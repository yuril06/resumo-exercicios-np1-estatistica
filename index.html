Como Calcular Cada Coisa
Como usar este guia: antes de fazer qualquer cálculo, leia a ordem aqui. Cada valor depende do anterior — pular uma etapa garante erro na prova.
📊 Tabela de Frequência — Ordem de cálculo
Esta é a parte que vale mais pontos. Siga EXATAMENTE essa ordem:
PASSO 0 — ANTES DE TUDO
Monte o Rol
Organize todos os dados em ordem crescente. Sem isso, nada funciona.
Ex: 3,1,2,1,3,2 → Rol: 1,1,2,2,3,3
↓
PASSO 1 — PRIMEIRO A PREENCHER
fi — Frequência Absoluta
Conte quantas vezes cada valor aparece no rol.
Não precisa de nada antes. É só contar.
Ex: valor 1 aparece 2× → fi = 2
⚠️ A soma de todos os fi deve ser igual a n.
↓ precisa do fi
PASSO 2 — DEPENDE DO fi
Fi — Frequência Acumulada
Some o fi da linha atual com o Fi da linha anterior.
Precisa do fi preenchido antes.
Primeira linha: Fi = fi (não tem linha anterior)
Demais linhas: Fi = fi atual + Fi anterior
Ex: fi=2, Fi anterior=4 → Fi = 2+4 = 6
⚠️ O último Fi deve ser igual a n.
↓ precisa do fi e do n
PASSO 3 — DEPENDE DO fi E n
fri — Frequência Relativa
Divide o fi pelo total de dados (n).
Fórmula: fri = fi ÷ n
Ex: fi=4, n=12 → fri = 4÷12 = 0,33
⚠️ A soma de todos os fri deve ser 1,00 (ou muito próximo).
↓ precisa do fri
PASSO 4 — DEPENDE DO fri
% — Frequência Percentual
Multiplica o fri por 100.
Fórmula: % = fri × 100
Ex: fri=0,33 → % = 0,33×100 = 33%
⚠️ A soma de todos os % deve ser 100%.
Resumo da ordem: Rol → fi → Fi → fri → %  |  Nunca pule uma etapa.
📊 Tabela com Classes (variável contínua) — Ordem
PASSO 1
AT — Amplitude Total
Fórmula: AT = maior valor − menor valor
Não precisa de nada antes. É só subtrair.
Ex: maior=9,5, menor=2,5 → AT = 7
↓ precisa do AT e n
PASSO 2
k — Número de Classes
Fórmula: k = √n → arredonde para cima
Precisa saber n (total de dados).
Ex: n=20 → √20 = 4,47 → k = 5
↓ precisa do AT e k
PASSO 3
h — Amplitude de cada Classe
Fórmula: h = AT ÷ k → arredonde
Precisa do AT e do k calculados antes.
Ex: AT=7, k=6 → h = 7÷6 = 1,16 → use 1,2
↓ com h em mãos, monte as classes
PASSO 4
xi — Ponto Médio de cada Classe
Fórmula: xi = (limite inferior + limite superior) ÷ 2
Precisa das classes montadas.
Ex: classe 100–120 → xi = (100+120)÷2 = 110
↓ precisa do xi e fi
PASSO 5 — só pra média agrupada
xi × fi — coluna extra
Multiplica ponto médio pela frequência de cada classe.
Some toda a coluna → divida por n → média agrupada.
Ex: xi=110, fi=4 → xi×fi = 440
Resumo: AT → k → h → monta classes → fi → xi → xi×fi → média
📐 Média, Mediana e Moda — Ordem
Média Simples
1. Some todos os valores
2. Divida pela quantidade (n)
Não depende de nada antes.
Mediana
1. Monte o rol (ordem crescente) — obrigatório
2. Se n ímpar: posição = (n+1)÷2, pegue esse valor
3. Se n par: pegue os valores das posições n/2 e n/2+1, tire a média
Depende do rol.
Moda
1. Monte o rol (facilita muito)
2. Conte quantas vezes cada valor aparece
3. O que aparecer mais = moda
Não precisa de cálculo. Só contagem.
Mediana Agrupada — Fórmula Md = L + [(n/2 − Fi₋₁) ÷ fi] × h
1. Precisa da tabela com Fi montada
2. Ache n/2 (metade do total)
3. Encontre a classe mediana: primeira onde Fi ≥ n/2
4. L = limite inferior dessa classe
5. Fi₋₁ = Fi da classe ANTERIOR
6. fi = frequência da classe mediana
7. h = amplitude da classe
Depende da tabela de frequência completa.
📏 Dispersão — Ordem obrigatória
Esses três sempre nessa ordem. Um depende do anterior.
PASSO 1 — SEMPRE PRIMEIRO
x̄ — Média
Calcule a média primeiro. Todos os outros dependem dela.
Fórmula: x̄ = soma de todos ÷ n
↓ precisa da média
PASSO 2 — MONTE A TABELA
xi − x̄ — Desvio de cada valor
Subtraia a média de cada valor.
Pode dar negativo — é normal!
Ex: xi=4, x̄=8 → 4−8 = −4
↓ precisa dos desvios
PASSO 3A — PARA O DESVIO MÉDIO
|xi − x̄| — Módulo do desvio
Tire o valor absoluto — transforma negativo em positivo.
Ex: −4 vira 4 | −2 vira 2 | 0 fica 0
Some todos os módulos → divida por n → Desvio Médio
PASSO 3B — PARA VARIÂNCIA E DP
(xi − x̄)² — Desvio ao quadrado
Eleve cada desvio ao quadrado.
Ex: −4² = 16 | −2² = 4 | 0² = 0
Some todos → divida por n → Variância (σ²)
Tire a raiz da variância → Desvio Padrão (σ)
Resumo da ordem:
Média → desvios (xi−x̄) → módulos → DM
Média → desvios (xi−x̄) → quadrados → soma → variância → √ → DP
Dica de ouro: Monte sempre a tabela no papel com as colunas: xi | xi−x̄ | |xi−x̄| | (xi−x̄)². Preencha linha por linha, da esquerda pra direita. Nunca pule coluna.

📊 O que é Estatística?
Área da matemática que coleta, organiza, analisa e interpreta dados para tirar conclusões.
Descritiva
Organiza e descreve os dados. Usa tabelas, gráficos e medidas. Não vai além do que foi coletado.
Inferencial
Analisa uma amostra e faz generalizações sobre a população inteira.
👥 População, Amostra, Censo e Amostragem
ConceitoO que éExemplo
PopulaçãoConjunto total de elementos estudadosTodos os 300 alunos de ADS
AmostraParte selecionada para representar o todo60 alunos sorteados
CensoEstudo de TODOS os elementosColetar nota de todos os 300
AmostragemO método usado para selecionar a amostraO sorteio dos 60 alunos
Dica: Censo = todos. Amostragem = o método. Amostra = a parte que foi escolhida.
🎯 Tipos de Amostragem
1
Aleatória Simples — todos têm a mesma chance. Feita por sorteio.
Ex: turma de 100 alunos → numera de 1 a 100 → sorteia 20.
2
Proporcional Estratificada — divide em grupos e retira amostras proporcionais.
200 alunos (100 no 1º sem, 60 no 2º, 40 no 3º). Amostra de 50:
1º sem → (100÷200)×50 = 25 | 2º sem → 15 | 3º sem → 10
📋 Dados Brutos e Rol
Dados brutos — coletados sem organização. Difíceis de analisar.

Rol — dados em ordem crescente ou decrescente. Sempre o primeiro passo.
Brutos: 1,70 / 1,60 / 1,65 / 1,78 / 1,71
Rol: 1,60 / 1,65 / 1,70 / 1,71 / 1,78

1

2

3

1

2

2
% = fri × 100 | Exemplo: 0,33 × 100 = 33%
